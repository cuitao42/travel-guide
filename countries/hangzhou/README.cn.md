# 🇨🇳 杭州 (Hangzhou)

> **旅行特色**：西湖山水、江南历史、灵隐古刹、京杭大运河，以及小笼包、片儿川与杭帮菜。本篇以**两日行程**为主线，另提供一日游及亲子游取舍建议。部分开放时间、交通班次、餐厅评价与费用来自行前攻略，出发前需重新核实。

## 📍 概览
- **第一次来杭州**：优先体验 **西湖 + 灵隐寺/飞来峰 + 水上巴士 7 号线及南宋老城**，分别体验杭州的山水、佛教文化、城市水脉与南宋历史。
- **推荐停留**：两天较为合适；只有一天时优先西湖，不建议把灵隐、大运河、九溪全部塞进同一天。
- **最佳游览节奏**：第一天以西湖为主；第二天清晨乘东河水上巴士，上午游南宋老城，下午游灵隐寺和茅家埠。
- **夏季提醒**：杭州夏天湿热，西湖周边露天步行多；备好水、防晒、防蚊用品，遇雷雨不要登宝石山。
- **住宿区域**：湖滨/龙翔桥、凤起路/嘉里中心、武林广场交通方便；下面的行程住宿参考为 **杭州城中香格里拉（Midtown Shangri-La）**。

## 🗓️ 推荐两日游行程

### D1｜西湖环线 + 宝石山 + 夜景

| 时间 | 行程 | 提示 |
| --- | --- | --- |
| 11:00–12:15 | 抵达杭州、酒店寄存行李、简单午餐 | 不要为了排网红餐厅耽误下午 |
| 12:45–14:30 | 湖滨码头 → 三潭印月 → 花港观鱼 | 上岛参观后选花港方向离岛，减少回头路 |
| 14:30–15:15 | 花港观鱼 | 红鱼池、湖边树荫，适合亲子 |
| 15:15–16:45 | 苏堤 → 曲院风荷 / 岳庙附近 | 可走苏堤核心段，太热时利用观光交通 |
| 16:45–18:10 | 西泠桥 → 孤山 → 平湖秋月 → 白堤 → 断桥 | 西湖北线经典步行段 |
| 18:10–19:20 | 宝石山 / 保俶塔周边 | 从北山路附近上山；不适合雨天或体力不足者 |
| 19:30 前后 | 湖滨晚餐 / 西湖音乐喷泉（若开放） | 演出时段以当天公告为准 |

**重点路线**：湖滨 → 三潭印月（游船）→ 花港观鱼 → 苏堤 → 曲院风荷 → 孤山 → 白堤 → 断桥 → 宝石山。全程较充实，不适合每一段都慢慢逛；如带幼童，建议二选一：**苏堤全程**或**宝石山登高**。

### D2｜水上巴士 7 号线 + 南宋老城 + 灵隐寺 + 茅家埠 + 断桥

**推荐路线**：坝子桥码头 → 水上巴士 **7 号线** → 梅花碑终点站 → 德寿宫 → 胡雪岩故居 → 望仙阁 → 鼓楼 / 南宋邮局 → 中山南路午餐及赵奶奶葱包桧 → 灵隐寺 / 飞来峰 → 灵隐寺东南门一带乘公交 → 茅家埠 → 公交返回西湖 → 断桥（时间允许时）。

| 时间 | 行程 | 提示 |
| --- | --- | --- |
| **06:45–07:20** | 从酒店出发，前往 **坝子桥水上巴士码头** 排队 | 早点到始发站；出发前确认首班船时间、天气和运营公告 |
| **07:40–08:40** | 乘坐水上巴士 **7 号线** 至 **梅花碑** 终点 | 约一小时作为规划余量；船小、人多，实际发船及候船时间不保证 |
| **08:40–09:15** | 梅花碑 → 德寿宫周边，早餐 / 步行 | 若德寿宫尚未开馆，可先在周边老街散步 |
| **09:15–10:15** | **南宋德寿宫遗址博物馆**（选去） | 请确认预约及当日开放时段；不可入馆则看建筑外观后继续 |
| **10:15–11:00** | **胡雪岩故居**（选去） | 清末杭州历史建筑，入内参观需注意票务与开放时间 |
| **11:00–11:40** | **望仙阁登高** | 位于鼓楼附近的中山南路；可俯瞰老城，开放与登阁条件以现场为准 |
| **11:40–12:15** | **鼓楼 → 南宋邮局打卡** | 顺路看南宋御街、鼓楼街巷，确认邮局具体门店位置与营业情况 |
| **12:15–13:15** | **中山南路老杭州街区午餐**，寻找 **赵奶奶葱包桧** | 小吃摊营业时间不固定，未开门就选当地面馆或小吃店 |
| **13:15–14:00** | 乘车前往 **灵隐飞来峰景区** | 下午交通可能拥堵，预留换乘时间 |
| **14:00–16:00** | **飞来峰造像 → 灵隐寺** | 预约**下午时段**；时间有限，永福寺等延伸点暂不安排 |
| **16:00–16:45** | 从**灵隐寺东南门方向**离开，乘公交前往 **茅家埠** | 依实际可通行出口、最近公交站及百度地图实时线路确定，不将寺门视为公交站 |
| **16:45–17:15** | **茅家埠** 湖湾与湿地短途散步 | 只走一小段，作为清静的西湖西岸体验 |
| **17:15–17:45** | 公交返回西湖北岸，**可选重游断桥** | 断桥为机动项目；若返程交通慢，直接回酒店 |

**时间与风险提醒**：第二天计划紧凑，尤其是 7 号线候船、德寿宫入馆、午后灵隐寺和晚间赶高铁。**不建议为等船或某个小吃摊牺牲灵隐寺预约及返程时间**。如果上午排队超过约 30–45 分钟，可改地铁/网约车直达梅花碑或德寿宫；如果下午延误，按顺序删去望仙阁登高、茅家埠漫步、断桥重游。灵隐寺请预约 **下午场**。

**7 号线季节提示**：2026 年 7 月过坝子桥 **07:40–10:20、15:40–17:00** 等分段服务时段；这只是历史公告，不是未来出行的固定班次。请当天核查“杭州水上巴士”公告，也可致电 **0571-88024168**。另有 2026 年 10 月报道提及热门站点排队较久，所以早起排队是合理安排。

# 🌊 西湖 (West Lake)

## 🏞️ 精华路线与景点
- **三潭印月**：西湖十景之一，人民币一元纸币背面的图案取景于此；通常需乘船上岛。建议**从湖滨上船、花港方向离岛**，但登船码头、出岛线路依当天运营安排确认。
- **花港观鱼**：红鱼池、花木与临湖景色，亲子游尤其适合。请遵守景区关于投喂动物的规定。
- **苏堤春晓**：苏轼主持疏浚西湖时修筑的长堤，全长约 2.8 公里；走完全程需预留约 1 小时以上，停留拍照则更久。
- **曲院风荷**：夏季观赏荷花的代表地点，适合与苏堤北段连游。
- **孤山、平湖秋月、白堤**：湖景与历史人文相结合，从西泠桥走向断桥路线连贯。
- **断桥残雪**：西湖经典地标，夏季欣赏桥景与周围湖景，不必期待雪景。
- **宝石山 / 保俶塔**：适合从高处俯瞰西湖、白堤与城市天际线；注意防滑、雷雨及日落后下山安全。
- **雷峰塔 / 净慈寺**：如果不去宝石山，可在西湖南岸增加雷峰塔观景和净慈寺，形成较轻松路线。

## 🚣 游船、步行与亲子骑行
- **游船**：在一公园、二公园等湖滨码头询问可否上 **三潭印月** 并从 **花港观鱼** 出岛；部分线路需要分段候船。
- **步行**：苏堤、白堤、孤山适合徒步，夏季中午尽量避开长距离暴晒。
- **亲子骑行**：湖边可查询带儿童座椅的公共自行车或“小红车”，使用前在**叮达出行**等官方渠道核实车辆、租还站点、收费及儿童乘坐规定；不要假定所有环湖步道都能骑车。
- **西湖音乐喷泉**：以 **19:30** 为参考，是否演出以及具体场次应查当地最新公告，不要专程以固定时刻作为保证。

# 🛕 灵隐寺 & 飞来峰
- **主要看点**：飞来峰石刻造像、灵隐寺殿宇和佛教文化，适合安排 **2.5–3 小时**。
- **D2 下午推荐顺序**：飞来峰造像 → 灵隐寺主要殿宇（大雄宝殿、药师殿等）→ 从东南门方向按现场指示离开；选去永福寺。
- **预约提醒**：**2026 年政策**为灵隐飞来峰景区实行免票、**实名分时预约**，上午场约 **07:30–12:00**、下午场约 **12:00–17:00**。建议通过微信或支付宝 **“杭州灵隐飞来峰”** 官方入口确认最新政策、名额、开放和预约时段，切勿只凭历史攻略现场碰运气。
- **出行建议**：暑期注意防暑，提前确认景区出口、公交站及赴茅家埠的实际交通方式。
- **D2 游后延伸**：从灵隐寺周边搭乘公交前往茅家埠短走，再乘公交返回西湖北岸；如时间紧张，略去断桥重游。
- **官方信息参考**：[杭州西湖风景名胜区管理委员会](https://westlake.hangzhou.gov.cn/)。

# 🚤 京杭大运河 & 老街

## 🛶 水上巴士：
- **7 号线（D2 清晨首选）**：规划从 **坝子桥始发站** 乘船，依次经过宝善桥、广安新桥、潮鸣寺巷、菜市桥、葵巷、浙二医院、城站火车站等，至 **梅花碑** 终点下船；可接续德寿宫、胡雪岩故居和南宋老街。参考票价约 **3 元**，但班次、路线、运力及支付方式可能变化。
- **早到排队**：7 号线部分船只容量较小，节假日及热门时段排队可能很久，尽量在首班前到达。因高温、水位或检修可能调整或停运，出发前请查“杭州水上巴士”官方信息。
- **1 号线**：经武林门、信义坊、拱宸桥等，适合专程体验京杭大运河主线。
- **备选交通**：如果等船超过约 30–45 分钟，应改地铁/网约车前往德寿宫一带，避免压缩下午灵隐寺时间。

## 🏯 南宋老城：梅花碑至中山南路
- **南宋德寿宫遗址博物馆**：南宋宫殿遗址与相关展陈，上午优先参观；请提前确认预约政策与实际开放时间。
- **胡雪岩故居**：可了解晚清商人胡雪岩及杭州传统宅院建筑，适合从德寿宫顺路前往。
- **望仙阁**：位于**中山南路 468 号、鼓楼附近**，既可登高看胡雪岩故居、吴山一带，也能了解阁下的南宋手工作坊考古遗址；据公开旅游信息参考开放时段为周二至周日 **09:30–12:00、13:30–16:30**，最终以现场为准。
- **鼓楼 / 南宋御街 / 南宋邮局**：老城拍照、历史街区与主题邮局打卡；如果邮局没有开放，不影响主路线。
- **中山南路午餐与赵奶奶葱包桧**：先走访老杭州街区，再寻找葱包桧小店。

## 🏘️ 其他大运河沿岸景点
- **拱宸桥**：京杭大运河杭州段代表性古桥，适合了解漕运历史。
- **桥西历史文化街区**：传统街巷、手工艺与运河工业文化。
- **中国京杭大运河博物馆、刀剪剑 / 伞 / 扇博物馆**：需要专门安排半日，注意休馆日。
- **小河直街、大兜路**：适合运河边散步、喝茶和体验市井生活。

# 🍜 杭州美食

## 🥟 传统小吃 & 早餐
- **虾肉小笼包、馄饨、牛肉粉丝**：**新丰小吃**，推荐作为早饭或简单午餐；虾肉馄饨、洋糖糕。
- **小葱生煎包**：**赵宝美点心**（城头巷 108 号），可在其他时间尝试；D2 午餐优先中山南路老城小吃。
- **咸豆浆、油条**：**游埠豆浆**，适合不赶时间的早餐。
- **葱包桧**：杭州特色传统小吃，通常将油条与葱裹在饼皮中煎制。
- **烧麦、鲜肉榨菜月饼**：可关注景芳周大姐、六贤记等。

## 🍜 杭州面
- **片儿川**：雪菜、笋片、肉片等配料组合的经典杭州面。
- **虾爆鳝面**：虾仁、鳝段配面；**拌川、腰花拌川** 也值得尝试。
- **餐厅备选**：**奎元馆、菊英面馆、小狗面馆、方老大面**；根据当天实际动线找顺路分店。

## 🍖 杭帮菜 & 正餐
- **代表菜**：东坡肉、龙井虾仁、油爆虾、蟹黄豆腐、卤素鸡及其他江浙家常菜。
- **顺路餐厅**：**叶马**（嘉里中心一带）、**金猪餐厅**、**新新饭店 1913**、**德明饭店**、**杭三姐妹** 等；营业信息和菜单以当日为准。
- **知味观**：可品尝小吃或东坡肉；部分旅行评价认为东坡肉比部分门店的小笼包更出彩。
- **新白鹿、外婆家、绿茶**：方便作为顺路备选，价格和环境较易接受，但不必为此专门排长队。
- **蟹黄面**：可考虑 **李百蟹蟹黄面、蟹记王**，通常比普通汤面贵。
- **夜市/美食街**：**武林夜市、胜利河美食街、大兜路**，适合结合晚间散步选餐。

# 🏨 住宿 & 交通

## 🛏️ 住宿
- **湖滨 / 龙翔桥**：第一次来杭州、以西湖为主时方便。
- **嘉里中心 / 凤起路 / 武林广场**：餐饮商场多，适合西湖与其他城区景点间交通。
- **杭州城中香格里拉（Midtown Shangri-La）FHR**：离嘉里中心近。若通过特殊酒店项目预订，早餐人数、餐饮额度、房型升级等**以订单条款及酒店实际确认为准**，不要根据网络他人经历推断权益。

## 🚇 出行实用提醒
- **公交 + 地铁 + 网约车**：D2 早上前往坝子桥码头，下午从南宋老城去灵隐寺；灵隐寺至茅家埠以及返回西湖应使用实时公交导航确认。
- **水上巴士 7 号线**：本次是清晨重点体验，候船时间、限载及临时停航不可控，需保留陆路备选。
- **杭州东站**：如果乘坐 **20:00 火车**，建议预留充分的取行李、进站和安检时间；不要把下午行程排到最后一刻。
- **暑期高温雷雨**：山路、游船、露天活动可能受天气影响。准备室内博物馆、餐饮休息作为备选。
- **高铁购票**：[中国铁路 12306](https://www.12306.cn/)。

## 🗓️ 如果只有一天
- **轻松版**：湖滨 → 三潭印月 → 花港观鱼 → 苏堤一段 → 雷峰塔 / 净慈寺（二选一）→ 湖滨夜景。
- **步行摄影版**：白堤 → 断桥 → 孤山 → 曲院风荷 → 苏堤，傍晚视天气登宝石山。
- **历史文化版**：上午灵隐寺/飞来峰，下午西湖核心景区；**不再增加拱宸桥**。

## 🗺️ 更长时间值得专程去的地方
- **九溪、龙井、十里琅珰、云栖竹径**：山林、茶田与徒步，更适合另留半天到一天。
- **茅家埠、浴鹄湾**：避开西湖核心人潮，感受湿地与湖湾景色。
- **五柳巷**：可作为德寿宫附近的延伸点；本次 D2 已安排德寿宫和胡雪岩故居，不必再增加绕路。
- **西溪湿地**：另行安排较长时间，不建议在紧凑两天行程中硬塞。
