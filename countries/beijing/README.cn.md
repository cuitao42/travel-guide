# 🇨🇳 北京 (Beijing)

> **旅行特色**：北京有完整的皇家宫殿与园林、庄严的中轴线、雄伟的长城、古老的胡同寺院，也有科技馆、大学和现代奥运建筑。以下按区域整理景点、交通、预约和美食，并提供可以自由组合的游览路线。

## 📍 概览

- **推荐停留**：初次游览可安排约 **5–7 天**；喜欢历史、博物馆或想同时游览两段长城，适合停留更久。
- **核心景点**：天安门广场、故宫、景山公园、国家博物馆、颐和园、天坛、长城、雍和宫、国子监、中国科学技术馆。
- **适合季节**：春秋适合长时间步行；**北京夏季炎热、日晒强**，宫殿广场和长城尤其要注意防晒补水；冬天干燥寒冷，长城山风较大。
- **交通**：市区地铁为主，配合公交与步行；长城可选择高铁、旅游巴士、接送团或包车。
- **住宿区域**：王府井、前门/大栅栏、崇文门、东单等地，便于游览市中心景点和乘地铁出行。

| 主题 | 景点组合 | 游览建议 |
| --- | --- | --- |

# 🏯 故宫、天安门与北京中轴线

## 🇨🇳 天安门广场：升旗、降旗与周边建筑

- **升旗与降旗**：可以根据兴趣选择清晨升旗或傍晚降旗。升旗时间随日出变化，想观看升旗要提前出门，排队、安检、步行都需要时间。注意需要提前预约。
- **天安门广场**：中心地标之一，可与人民英雄纪念碑、人民大会堂外观、国家博物馆串联参观。注意需要提前预约。
- **毛主席纪念堂**：位于广场南侧，可与广场游览结合，参观前留意预约及随身物品规定。
- **天安门城楼**：如果想登楼，可与故宫入口附近的游览结合。
- **前门与大栅栏**：广场南面，适合吃饭、逛老街及拍摄正阳门、前门大街。
- **国家大剧院**：广场西侧的现代地标，适合顺路看建筑外观。

## 🏛️ 故宫博物院（紫禁城）

- **重点看点**：午门、太和殿、中和殿、保和殿、乾清宫、交泰殿、坤宁宫、御花园与神武门。
- **推荐路线**：**午门入宫 → 太和门 → 三大殿 → 乾清宫一带 → 御花园 → 神武门出宫**。喜欢建筑细节、钟表或珍宝的游客可以增加东西六宫及专题馆。
- **建议时间**：至少半天，喜欢历史建筑可安排更长时间；第一次去时，可以在入口处租一个讲解器，讲解或语音导览能帮助理解宫殿用途与历史故事。
- **预约入口**：中国国籍游客在微信小程序预约，如果8点抢不到，可以不停的刷，尤其是9点可能有大量的票放出。外籍游客可在[故宫博物院对外门票预约](https://bookingticket.dpm.org.cn/)用护照预约。老人，外籍人士，和中国籍持由海外使领馆签发的中国护照可以在故宫门口购票。
- 乘坐地铁8号线，在金鱼胡同站从C口出站。前往东华门：出站后向西步行约10至15分钟（或选择共享单车骑行），到达故宫的东华门。抵达午门：沿故宫东外墙（或顺着筒子河）向南步行约8至10分钟，即可到达故宫唯一的正门检票入口——午门。同时可以欣赏城墙、角楼及护城河景观。
- **游览方向**：宫内通常按南进北出组织参观，从神武门离开后很适合接着去对面的景山公园。

### 🧭 故宫周边的实用绕行路线：太庙、午门

- **太庙**（北京市劳动人民文化宫）与故宫不是同一个景区。可从地铁 **8 号线金鱼胡同 / 王府井一带** 或 **天安门东站**向太庙东门方向接近，减少在天安门广场一带折返。
- 一条常见步行路线是：**天安门东附近 → 太庙东门 → 太庙建筑群 → 太庙西门 → 故宫午门广场**。这样既能欣赏太庙，也可衔接故宫入口一带。
- **太庙**，也是一处适合拍摄皇家祭祀建筑的地方；园内游客服务中心有免费纪念章，可自带纸张盖章。

## 🌳 景山公园

- **万春亭**：从高处俯瞰故宫中轴线、层层殿宇与北京老城，视角很有代表性。
- **组合方式**：从故宫神武门出来，过街到景山南门👉主路缓坡上山，直达万春亭看全景，然后可继续到北海公园、什刹海。
- **摄影**：晴天上午或夕阳时适合拍摄中轴线；登高台阶不长，但需要爬坡。早上故宫那面逆光，钟鼓楼那面光线非常好，很漂亮，建议下午四五点去，光线适合拍故宫。
- 最快路径：西门进👉进门可见小卖部，沿小卖部向右走100米后，向左沿主路台阶上山，直达万春亭

## 🏺 中国国家博物馆

- 与天安门广场在同一片区域，适合对中国历史、考古、艺术感兴趣的游客。
- 快速进入国博，天安门东c口（可能会被管控），转d出口，排队10分钟刷证出，这时候直接冲进排队队伍，10分钟进入。注意不要先进天安门广场然后再去国博。天安门安检需要很长时间。
- 展厅很多，可以事先选择重点展览，不必一次看完所有馆。
- 国博人很多。不建议开始就去古代中国展馆排队。先上高楼层：进馆后直接乘电梯去 3层或4层 的专题展厅（比如三星堆）。这些展厅人流较少，环境清静。最后再后逛大热门：将“古代中国”（地下一层）或“复兴之路”（一层）放在 中午 12:00 - 13:30（午餐时间） 或 闭馆前 1.5 小时（如 15:30 之后）去排队，此时人流量会明显减少。
- 如果同时安排故宫和国博，两处都想认真参观时，最好分成不同游览时段甚至不同天。
- 如果当天要去天安门广场，不需要预约。从国博出来可以直接进去天安门广场。参观完可以看降国旗仪式。
- **预约**：除了官方微信小程序，也可以再携程app上预约。有人总结放票规律，门票刷新都在每分钟的10s-30s之间，每分钟放票都比上一次多一秒（假设这次是17:38:40放票，那么下次就是17:39:41
放票）。可以掐表（悬浮钟app），在下次放票之前的几秒刷新水果验证，在推测出的下一次放票时间上点击正确水果！
- 官方网站：[中国国家博物馆](https://www.chnmuseum.cn/)。

# 🌿 皇家园林：颐和园、圆明园与清华大学

## 🛶 颐和园（适合安排一整天）

- **核心看点**：万寿山、佛香阁、昆明湖、长廊、排云殿、十七孔桥、铜牛、南湖岛与苏州街等。
- **经典玩法**：从东宫门一带进入，看仁寿殿、长廊，沿昆明湖欣赏万寿山，再按兴趣登佛香阁、到十七孔桥或乘游船。或者从北宫门入，从西门或者东门出。
- **慢游理由**：颐和园面积很大，不只是一个宫殿景点。喜欢园林的人可以用一整天慢慢走湖岸、看建筑和山水布局。
- **体力分配**：昆明湖边步行距离长；夏季中午可选择坐船、在长廊阴凉处休息，或先走山上再到湖边。
- **游船**：可以体验昆明湖水上视角，游船码头、航线和季节运营随游览安排选择。

## 🏚️ 圆明园

- **看点**：园林水系、福海与西洋楼遗址，可从遗迹理解圆明园昔日的规模和近代历史。
- **游览建议**：圆明园很大，如果特别想看西洋楼遗址，可直奔相关区域；如果还要游颐和园，不必坚持全园徒步。
- **交通衔接**：从颐和园东宫门附近前往圆明园藻园一带可使用公交接驳。

## 🎓 清华大学

- **适合人群**：对中国大学、校园建筑与学术氛围感兴趣的游客。
- **校园看点**：清华园、荷塘、历史建筑与校园环境，可与颐和园、圆明园组成海淀一带的文化路线。
- **参观方式**：大学校园通常有访客登记或预约入口，可根据学校参观安排选用对应校门。
- **扩展**：也可结合北京大学周边游览，但不建议把两所大学和两座大型园林全部挤在同一天。

# 🧱 长城：八达岭与慕田峪

## 🏔️ 八达岭长城

- **特色**：历史名气大、交通选择较多，有经典的长城山脊风景。
- **南段与北段**：附件游记认为南段相对平缓；北段登高体验更鲜明，**北八楼**一带是受欢迎的登高目标。
- **索道玩法**：可乘索道至北七楼附近，再步行登北八楼，减少部分爬坡路程；适合希望看长城全景又不想全程徒步的人。
- **交通**：可以从北京乘高铁到八达岭长城站，也可参加旅游巴士或包车。自行前往时间弹性更大。
- **建议**：长城石阶常有陡坡，鞋子要防滑；夏天补水防晒，冬天防风。

## 🌲 慕田峪长城

- **特色**：山林环绕，长城在山脊起伏延伸，适合喜欢自然风光与城墙摄影的游客。
- **交通**：可参加**慕巴士**等市区往返接送团，省去多次换乘；也可以包车，出发和返回更自由。
- **游览**：路线一：西缆车上 14号敌楼 步行至20号好汉坡（最高点） 原路缆车下全程2.5小时，几乎不爬坡！14-18号敌楼超平坦，登顶俯瞰群山，长城全景。注意旅游旺季缆车需要排很长的队。
路线二：从北检票口进入北登山步道往上8号敌楼继续徒步至20号敌楼（好汉坡） 折返至8号敌楼北登山步道下。北登山步道上面，8号敌楼处有一个厕所。全程大概4个小时左右。
路线二：从南检票口进南登山步道往上（纯楼梯，比爬长城累，但20分钟左右就到了） 6号敌楼 徒步至1号敌楼（大角楼） 折返至6号敌楼 继续徒步至20号敌楼（好汉坡） 最后从14号敌楼乘坐缆车下山或者从10号敌楼走下去到达北检票口，一次打卡慕田峪长城整个路段。
- 如果没有体力，到20号敌楼（好汉坡）打卡就可以了。如果有体力可以从19号敌楼左侧很陡的步道继续爬到21至23号敌楼。
- 如果跟团，注意不要去团推荐的午饭，吃饭就没有时间登长城了。
- 注意：爬长城前要充分热身，控制节奏，量力而行，如果在爬长城过程中突然发生肌肉抽筋，切勿慌张，请立即停止运动并移步至安全平稳的地方，反向拉伸肌肉，补充水分与电解质，切勿强行蜷缩。

必打卡敌楼详解：
14号敌楼：“不到长城非好汉“石碑所在地，必拍！站在石碑旁，背景是连绵的长城，氛围感直接拉满，朋友圈九宫格C位预定地建议穿浅色系衣服，拍出来更出片～
15号敌楼：电影《非诚勿扰》取景地！自带电影滤镜，城墙的斑驳感和远处的山峦结合，随手一拍都是氛围感大片，文艺感直接拉满占可以站在城墙边，侧拍或者背影
20号敌楼：慕田峪长城最高点—英雄台！这里能360度无死角俯瞰长城全景，城墙像巨龙一样盘踞在山间，雄伟又壮观，风大的时候记得扶好帽子。

# 🛕 天坛、雍和宫与国子监

## 🌞 天坛公园

- **核心看点**：祈年殿、皇穹宇、回音壁、圜丘坛，是理解明清皇帝祭天礼制的代表性建筑群。
- **建议**：天坛园区较大，可从一侧入园，按祈年殿、丹陛桥、皇穹宇、圜丘等景点顺路参观。
- **参观节奏**：可安排半天，再接前门、大栅栏、天桥一带。

## 🧘 雍和宫

- 北京著名的藏传佛教寺院，有殿宇、佛像与宗教文化氛围。
- 参观时保持安静，遵守殿内拍照、礼佛及香火方面的规定。
- 雍和宫与国子监、孔庙相距不远，很适合连在一起步行游览。

## 📚 国子监与孔庙

- **国子监**：了解元、明、清时期的官学、教育制度与古代读书文化。
- **孔庙**：以祭孔传统与历史建筑为主要看点。
- **推荐顺序**：**雍和宫 → 国子监街 → 孔庙 / 国子监**，沿胡同步行即可。

# 🔬 科技馆、奥林匹克公园与城市地标

## 🧪 中国科学技术馆

- **推荐理由**：中国科技馆适合喜欢科学、动手体验及球幕电影的孩子和青少年。
- **游览方式**：选择感兴趣的常设展厅、互动装置和特效影院，适合安排半天至大半天。
- **官方入口**：[中国科学技术馆](https://cstm.cdstm.cn/)。

## 🏟️ 鸟巢、水立方与奥林匹克公园

- **国家体育场（鸟巢）**：2008 年北京奥运会的代表建筑，外部钢结构造型很有辨识度。
- **国家游泳中心（水立方 / 冰立方）**：可与鸟巢一起欣赏现代奥运建筑。
- **奥林匹克公园**：白天适合散步看建筑，夜间灯光更有城市氛围。
- **顺路组合**：科技馆结束后，步行或乘车到鸟巢、水立方一带游览。

## 🛍️ 王府井

- 北京中心城区的商业街，适合逛百货、吃饭及感受现代商业氛围。
- 与天安门、东单一带交通相连，可作为皇城游览后的用餐或晚间逛街地点。

# 🏘️ 胡同、北海与什刹海

## 🚶 南锣鼓巷

- 以北京胡同和街巷商业见长，适合走走看看胡同格局、院落外观、小店与小吃。
- 主街游客多，想体验更安静的老北京街区，可以走进周边允许通行的支巷。

## 🛎️ 鼓楼、钟楼与什刹海 / 后海

- **鼓楼、钟楼**：北京中轴线北段的重要地标，周边保留传统胡同风貌。
- **什刹海与后海**：湖岸散步、看夕阳和胡同街区，适合傍晚到晚上。
- **组合**：**南锣鼓巷 → 鼓楼 → 什刹海 / 后海**；有兴趣可增加恭王府。

## 🌳 北海公园

- 可以看到白塔、湖景、皇家园林布局和北京老城景观。
- 与景山、故宫北侧区域较近，适合在皇城路线之后慢游。

# 🥟 北京美食

## 🍜 经典小吃与早餐

- **老北京炸酱面**：黄酱肉丁配面条与多样菜码。
- **包子、油条、豆浆**：早餐容易选择，也适合早出门赶升旗或长城时吃。
- **炒肝**：北京传统早餐，附件推荐过**会仙居**。
- **豆汁儿与焦圈**：口味特别，适合想体验老北京饮食的游客。附件提到大栅栏的**尹三豆汁**和“五小福”组合。
- **卤煮火烧**：北京特色内脏小吃，附件提到**小肠陈**。
- **炖吊子**：传统北京菜，附件提到**砂锅居**。

## 🥩 正餐

- **北京烤鸭**：适合安排一顿正式北京餐。
- **涮羊肉**：传统铜锅涮肉，注重羊肉、麻酱蘸料和炭火风味。
- **聚宝源**：附件推荐的老字号清真涮羊肉店，**牛街总店**名气大，也提到**大栅栏分店**方便与前门老街游览结合。

# 🚇 交通与参观小贴士

## 🎫 热门景点预约与证件

- **故宫**：[故宫预约网站](https://bookingticket.dpm.org.cn/)；到馆时使用购票证件，游客较多时提前留出排队时间。
- **天安门广场**：升降旗观礼、广场入场与周边景点各有对应安排，建议将安检时间计入行程。
- **毛主席纪念堂**：[预约入口](https://jnt.mfu.com.cn/page/)。
- **中国国家博物馆**：将预约时段与广场周边交通一起考虑。
- **清华大学**：如计划入校参观，提前选择官方访客途径。
- **中国科学技术馆**：热门时段先确定展厅及影院票务。

## 🚉 路线安排建议

- **市中心**：天安门、故宫、景山、公园和前门区域，步行与安检往往比地铁车程更耗时。
- **颐和园与圆明园**：两个都是大园区；体力有限时把颐和园放在首位。
- **长城**：选择一段即可，尽量早出发。高铁或接送巴士的车站与集合点要对应具体路线。
- **科技馆与鸟巢**：地理位置相近，适合组合。
- **雍和宫与国子监**：适合步行串联，再去附近胡同慢游。

## ☀️ 季节建议

- **春季**：公园、皇家园林与胡同散步很舒服。
- **夏季**：广场、故宫院落、天坛及长城的阴凉处较少；上午早些游览室外，午后可去博物馆与科技馆。
- **秋季**：颐和园、长城山林和北京街景适合摄影，适合更长时间户外活动。
- **冬季**：空气干燥且有寒风，游长城时尤其注意防风保暖；冰雪景观也别有韵味。
