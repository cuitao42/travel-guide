# 🇨🇳 南京 (Nanjing)

> **旅行特色**：南京兼具六朝古都、明代都城与中国近现代历史的重要遗迹。适合沿着历史脉络参观纪念馆、总统府、南京博物院、明孝陵与中山陵，晚上再欣赏秦淮河夜景。本文提供可自由调整的**两日游参考路线**。

## 📍 概览
- **建议停留**：初访南京可安排 **2–3 天**；两天能走核心景点，但需要较早出门、合理使用地铁与景区接驳车。
- **两条主线**：第一天认识近现代历史与秦淮文化；第二天集中游览钟山风景区的明代与民国历史遗迹。
- **住宿建议**：**大行宫 / 新街口 / 夫子庙周边**交通较方便；如果清晨或晚间从南京南站乘车，住南站附近也有优势。
- **季节**：春秋适合步行；**南京夏季炎热潮湿**，钟山景区台阶与露天步道较多，需做好防晒、防暑、补水；梅雨季注意雨具。冬天湿冷，山区风更大。
- **预约优先级**：**侵华日军南京大屠杀遇难同胞纪念馆、南京博物院、中山陵**。周一及法定节假日的开放政策需单独查询。

## 🗓️ 推荐两日游路线

### D1｜大屠杀遇难同胞纪念馆 → 总统府 → 南京博物院 → 夫子庙秦淮夜景

| 建议时段 | 行程 | 重点与提醒 |
| --- | --- | --- |
| 08:30–10:45 | **侵华日军南京大屠杀遇难同胞纪念馆** | 预约上午较早的时段，认真参观，保持肃穆 |
| 10:45–11:45 | 午餐 / 前往大行宫一带 | 可吃汤包、小笼包、盐水鸭、鸭血粉丝汤等；不要特意为网红店排队 |
| 11:45–13:30 | **总统府** | 中轴区 → 西区 → 东区；重点了解近现代历史 |
| 13:30–14:00 | 前往南京博物院 | 可结合地铁 2 号线，或视体力打车 |
| 14:00–16:45 | **南京博物院** | 历史馆、民国馆及感兴趣的特展，建议预约下午场 |
| 17:00–18:30 | 晚饭与休息 | 避免在盛夏持续暴晒，尽量就近用餐 |
| 19:00–21:00 | **夫子庙 → 江南贡院 / 中国科举博物馆 → 秦淮河** | 文德桥赏夜景；有余力可延伸至老门东 |

**行程强度提醒**：这是内容比较丰富的一天。纪念馆和南京博物院都不适合匆忙走过；如果希望各馆仔细参观，建议将总统府或南京博物院挪到第三天。尤其纪念馆所呈现的历史较沉重，同行者可以按自己的感受调整节奏。

### D2｜明孝陵（朱元璋）→ 美龄宫 → 中山陵 → 音乐台 → 灵谷景区

| 建议时段 | 行程 | 重点与提醒 |
| --- | --- | --- |
| 07:30–10:00 | **明孝陵**（1号门） | 明太祖朱元璋与马皇后的陵寝；石象路、神道、方城明楼 |
| 10:00–10:45 | **美龄宫**（可选） | 民国建筑与历史陈列；时间紧可以略去 |
| 11:00–12:30 | **中山陵** | 博爱坊、陵门“天下为公”、碑亭、祭堂；需预约 |
| 12:30–13:30 | 午餐、休息 | 景区较大，利用休息与接驳时间补充体力，可自带食物 |
| 13:30–14:30 | **音乐台** | 中山陵附近，半圆形露天音乐建筑，可观赏鸽群 |
| 14:30–16:45 | **灵谷寺 / 灵谷塔 / 灵谷景区** | 古寺及林间环境；视开放时间与体力取舍 |
| 17:00 后 | **景区出口 → 公交 → 地铁站** | 灵谷景区出口查看实时公交与末班车，接驳最近方便的地铁站 |

**路线建议**：**明孝陵 → 美龄宫 → 中山陵 → 音乐台 → 灵谷寺**。景点之间距离不短，可使用景区观光车，注意不同线路可能分别收费。出园后历史攻略曾使用 **202 路公交**接驳，但线路、车站与末班时间会变，务必以当天地图和站牌为准。

# 🏛️ 南京历史与市区景点

## 🕯️ 侵华日军南京大屠杀遇难同胞纪念馆
- **意义**：记录南京大屠杀历史、遇难者与幸存者的经历，也是了解中国抗日战争历史的重要场所。
- **参观建议**：至少预留 **2 小时**，按照馆内展陈顺序参观，不将这里作为普通拍照景点。
- **参观礼仪**：保持安静、尊重遇难者；**遗骨陈列室、“万人坑”等区域禁止或限制拍摄，应严格遵守现场标识**。
- **交通**：地铁 **2 号线云锦路站**附近，具体入口以预约信息为准。
- **预约**：一般实行免费实名预约，放票日期、闭馆日与开放时段以[纪念馆预约平台](https://exhibit.19371213.com.cn/yuyue/)为准。

## 🏛️ 总统府（南京中国近代史遗址博物馆）
- **推荐顺序**：**中轴区 → 西区 → 东区**。
  - **中轴区**：大堂、“天下为公”匾额、会客室与子超楼等。
  - **西区**：煦园、孙中山临时大总统办公室、相关历史建筑。
  - **东区**：行政院旧址、东花园等，可根据时间取舍。
- **建议时间**：**1.5–2.5 小时**。喜欢民国史与建筑的人可留更久。
- **交通**：地铁 **大行宫站**，从相应出口步行前往。
- **参观前**：核实预约、门票、停止入园时间及周一安排；参考[总统府官方网站](https://www.njztf.cn/opening_hours.html)。

## 🏺 南京博物院（Nanjing Museum）
- **重要区分**：**南京博物院**和“南京博物馆”不是一个名称，导航和预约时注意辨别。
- **看点**：历史馆、民国馆、艺术馆、特展馆等，馆藏丰富，适合系统了解江苏和中国历史文化。
- **时间**：建议至少 **2.5–3 小时**；如果认真看展，半天甚至更久都值得。
- **交通**：地铁 **2 号线明故宫站**附近。
- **预约**：关注实名预约放票时间、证件要求和闭馆安排；查看[南京博物院官网](https://www.njmuseum.org.cn/)。

## 🌃 夫子庙、江南贡院与秦淮河
- **夫子庙**：传统商业街区，夜景热闹；商业化程度较高，建议把重点放在历史文化和沿河景观。
- **江南贡院 / 中国科举博物馆**：中国古代科举制度的重要实物与历史展示地点，适合带学生参观。可预留 **1–1.5 小时**，夜间开放情况单独确认。
- **秦淮河**：推荐傍晚至夜间沿河散步，从**文德桥**及周边欣赏灯光、古建筑和水面倒影。
- **老门东**：传统街巷与小吃、店铺集中，可作为延伸目的地，不一定要与夫子庙全部走完。
- **推荐顺序**：**夫子庙 → 中国科举博物馆 → 登科长廊 → 文德桥 → 秦淮河 → 老门东（可选）**。
- **小贴士**：不必专门在夫子庙最热闹的街上吃正餐，附近居民街区或科巷等地通常也有多种选择。
- [中国科举博物馆开放信息](https://www.njiemuseum.com/canguan/1.html)

# 🌳 钟山风景区（紫金山）

## 🐉 明孝陵：朱元璋与明朝
- **历史背景**：明孝陵是明太祖**朱元璋**及马皇后的陵墓，是明代皇家陵寝建筑的重要代表。
- **重点路线**：**石象路 → 神道 → 金水桥 → 陵宫 / 方城明楼**，实际行走顺序可按入园口调整。
- **特色**：石兽、石人、山林古道与皇家陵寝建筑。春季梅花山赏梅，秋天树叶变色时也很值得来。
- **游览建议**：一般预留 **2–3 小时**；仔细看整片景区则需要更久。
- **入口**：推荐明孝陵景区-1号门进，步行距离最少。推荐乘坐景区电瓶车去美龄宫或者中山陵。

## 🏠 美龄宫（可选）
- 与民国历史有关的别墅建筑及展陈，可在明孝陵和中山陵之间顺道参观。
- 时间紧、天气炎热或同行者体力不足，可以略去，把时间留给明孝陵及中山陵。

## 🏛️ 中山陵：孙中山纪念建筑群
- **核心步行路线**：**博爱坊 → “天下为公”陵门 → 碑亭 → 长台阶 → 祭堂**。
- **预约**：中山陵陵寝核心区域通常实行**免费实名预约**，以[南京市中山陵园管理局](https://zschina.nanjing.gov.cn/)公告为准。
- **参观建议**：预留 **1–1.5 小时**，夏天台阶多、日晒明显，带水并量力而行。祭堂区域注意保持肃静。

## 🎼 音乐台
- 位于中山陵附近的半圆形户外建筑和草坪景观，以音乐演出场地和鸽群闻名。
- 适合短暂停留；热门时段人多，可以按兴趣决定是否入内。
- 推荐乘坐景区电瓶车去灵谷寺。

## 🌲 灵谷寺与灵谷景区
- **看点**：灵谷寺、灵谷塔及林间步道。灵谷塔登高有眺望视角，但是否开放和登塔条件需现场确认。
- **行程安排**：作为钟山线路的最后一站；若已经走累，可在音乐台后结束行程。
- **返程**：从**灵谷景区出口**看站牌乘公交前往方便换乘的地铁站。旧攻略提到 **202 路**，只作历史参考，以百度地图实时路线为准。
- **注意**：景区各设施停止入园、寺院开放及塔楼登塔时间可能不同，别到傍晚才期待全部能进入。

## 🎟️ 钟山门票与内部交通
- 中山陵预约与明孝陵、美龄宫、音乐台、灵谷景区门票**分别管理**；有时提供多景点联票。
- 联票约 **100 元**、音乐台约 **10 元**、美龄宫约 **30 元**，**仅为历史参考**，购票前以官方渠道为准。
- 景区范围大，观光车可能涉及不同路线及重复购票；看清路线图，切勿以为一张车票可任意坐全程。
- [中山陵园管理局旅游信息](https://zschina.nanjing.gov.cn/lyzx/202506/t20250623_5591074.html)

# 🥟 南京饮食推荐

## 🦆 来南京值得尝试的食物
- **盐水鸭 / 板鸭**：南京代表性鸭肴；可以在居民区的熟食店购买，优先看新鲜度、价格和当地客流。
- **鸭血粉丝汤**：常见老鸭汤底，搭配鸭血、粉丝和鸭杂，适合早餐或简餐。
- **汤包 / 小笼包**：注意汤汁烫口；可与鸭血粉丝汤组合成午饭。
- **牛肉锅贴**：底部焦脆、馅料多汁，是南京很有代表性的早点。
- **皮肚面**：南京特色汤面，可视口味选择不同浇头。
- **糕团、小元宵**：适合逛秦淮河与传统街巷时尝试。

## 🍴 店铺备选
- **鸭类熟食**：章云板鸭、金宏兴鸭子店等。
- **鸭血粉丝汤**：小潘记、鸭得堡、老盛庆等。
- **牛肉锅贴**：李记清真馆等。
- **小吃聚集区域**：**科巷、三七八巷、老门东**；购物和就餐前先查看实际营业情况、菜单及近期开店信息。

**两日路线中的用餐安排**：第一天参观纪念馆后，前往大行宫附近吃**汤包或小笼包 + 鸭血粉丝汤**，也可以购买一些盐水鸭；晚上秦淮河附近吃小吃。第二天钟山景区附近以便捷用餐、补水休息为主，不必为一家餐馆绕路。

# 🚇 交通、住宿与季节提醒

## 🚉 市内交通
- **地铁**：连接主要城区、南京南站及多个历史景点，是避开高峰拥堵的实用选择。
- **主要站点**：纪念馆常用 **云锦路站**；总统府为 **大行宫站**；南京博物院为 **明故宫站**；夫子庙可使用 **夫子庙站**。
- **钟山交通**：可从靠近明孝陵的入口开始游览，内部结合步行与接驳车。灵谷景区游览结束后，再乘公交接驳地铁；出行前通过高德地图、百度地图查看公交线路与末班时间。
- **南京南站**：乘高铁当天注意地铁时间、进站安检及站内步行时间，别将大型景点排到发车前一小时。

## ☀️ 天气与人流
- **夏季**：高温湿热，优先清晨参观明孝陵、中山陵等户外区域，正午尽量安排室内场馆和用餐；注意防晒、补盐补水。
- **梅雨与雷阵雨**：随身带轻便雨具，山林步道湿滑时缩短路线。
- **节假日 / 周末**：博物院、纪念馆、中山陵以及夫子庙易拥挤，应提前预约，并给交通留出余量。
- **秋季**：钟山山林、梧桐大道适合赏秋；比盛夏更适合长时间户外步行。

## 🏨 住宿区域
- **大行宫**：适合总统府、南京博物院、夫子庙之间往返，比较适合初次来南京。
- **新街口**：购物餐饮丰富、地铁方便。
- **夫子庙 / 秦淮河**：方便夜间散步，但热门地区可能人多、房价偏高。
- **南京南站**：适合铁路出行时间比较早或晚的游客，代价是部分景点通勤更远。

---

## 🗺️ 如果有第三天
- **南京明城墙（解放门 / 台城段）**：可从高处看玄武湖、紫金山与城景。
- **玄武湖 + 鸡鸣寺**：适合半天慢走，附近可关注南京古生物博物馆。
- **牛首山**：交通距离较远，最好单独安排半天或更久。
- **先锋书店、六朝博物馆、南京大学或东南大学周边**：按兴趣选择，校园开放政策需核实。
- **中华门城堡、老门东、南京城墙其他段**：适合偏爱古城防御建筑与慢游的人。

## ⚠️ 预约与资料时效
- 纪念馆、南京博物院和中山陵应**先预约，再确定日程**；场馆可能设周一闭馆、特殊纪念日管理及临时开放调整。
- 本文的景区票价、公交线路和开放时间可能变化，不能视为实时信息。
- 如果喜欢深度参观博物馆，建议将这份两日路线拆为 **三天**，不要为完成打卡而缩短重要展览的参观时间。
