# 🇭🇰 香港 (Hong Kong)

> **旅行特色**：维多利亚港与城市天际线、天星小轮、太平山顶、传统街市和茶餐厅、离岛与大屿山天坛大佛。本篇按交通、景点、支付和省钱技巧整理，适合根据兴趣自由组合游览。

## 📍 概览

- **主要区域**：九龙的尖沙咀、旺角、油麻地；港岛的中环、金钟、铜锣湾、太平山顶；大屿山的东涌、昂坪、天坛大佛和大澳。
- **气候**：夏季炎热潮湿，适合把户外海滨散步与有空调的博物馆、商场交替安排；秋冬适合爬山、看海和走街区。
- **交通**：港铁（MTR）、巴士、天星小轮和其他渡轮；前往机场还有机场快线、A/E 线机场巴士及东涌转 S1 的便宜走法。
- **预算玩法**：跨海坐天星小轮、从上水转巴士、在油麻地与旺角的街市及本地食肆吃饭、用东涌线 + S1 进出机场。

# 🚆 从深圳进入香港：陆路与海路

## 🚇 陆路一：罗湖口岸 → 港铁东铁线

1. 在深圳搭乘地铁 **1 号线**，到终点 **罗湖站**。
2. 步行至罗湖口岸过关，再前往香港侧的**罗湖站**。
3. 乘港铁**东铁线**南下，前往九龙及港岛，并根据目的地换乘。
4. 前往尖沙咀一带可搭港铁至**尖东**周边。罗湖—尖东普通车厢车费约 **HK$42**，车程约 **56 分钟**。

## 🚇 陆路二：福田口岸 → 落马洲 → 上水

1. 深圳乘**地铁 4 号线**至**福田口岸**，办理过关手续。
2. 在香港侧进入港铁**落马洲站**，坐东铁线**一站**至**上水站**。
3. 从上水继续乘港铁，或者改乘巴士到九龙。

### 💰 省钱方法：上水换巴士

- 在**上水巴士总站**乘九巴 **270A** 往九龙／尖沙咀方向，参考车费 **HK$16.2**。
- 另有人提到 **276B** 等从上水出发的巴士，适合按终点站选择。
- 如果当天主要靠巴士出行，可直接乘巴士，不一定要买港铁全日通；香港部分地铁站内换乘步行也比较长。

## ⛴️ 海路：深圳坐船到香港

- 海路适合希望通过客运码头或直接衔接香港机场的旅客，通常从深圳的客运码头选择对应的香港目的港。
- **一般入境香港市区**与**直达香港机场海天中转**是不同类型的航线；购票时先选择适合自己是否入境香港、是否需要办理行李手续的线路。
- 对准备从香港机场出发的人，海路与罗湖／福田口岸陆路可以根据行李、时间和预算比较。

## 🛂 从香港转机前往内地／第三地

- 持中国护照经香港过境：若目的地是内地或第三地，可以向承运航空公司说明**香港是中转地**，并准备后续机票、船票等资料，无需香港签证和通行证。
- 在香港机场转机，已有下一程登机牌且行李直挂时，可能无需入境；如果需要提取并重新托运行李，则应按对应的转机程序办理。
- 参考：[香港入境事务处：中国护照持有人入境安排](https://www.immd.gov.hk/eng/services/visas/overseas-chinese-entry-arrangement.html#21)、[香港机场转机指南](https://www.hongkongairport.com/tc/passenger-guide/transfer-transit/#2)。

# 💳 香港交通支付与通票

## 🚇 港铁（MTR）

- **八达通**是常用选择，可乘港铁、巴士及在不少商户付款。
- **支付宝／微信使用香港地铁乘车码**可用“乘车码”小程序搭乘港铁重铁网络（机场快线车站除外）。
- 港铁车票、游客票的**现金、电子钱包和信用卡付款方式**会因售票机、站点及购票产品不同而有所区别。口岸站购票可留有港币现金备用。
- 在罗湖、落马洲等口岸站使用八达通充值设备，以及跨境交通卡首次充值可能需要人工办理。

## 🎫 港铁游客全日通（Tourist Day Pass）

- 适合一天内频繁坐地铁的游客；从**首次进闸起 24 小时**计算。
- 原始资料记有成人 **HK$65／75** 两种参考售价，儿童 **HK$30**；儿童游客全日通面向 **3–11 岁**。
- 一些口岸站并不销售此类游客票，笔记建议到上水等市区车站购买。
- 是否值得买：如果当天只坐一两次地铁，其余以步行和巴士为主，不一定划算。
- [港铁游客全日通介绍](https://www.mtr.com.hk/ch/customer/tickets/day_pass_tourist.html)

## 🚌 巴士：刷卡、Apple Pay、支付宝与微信

- 可以直接用 **Visa、Mastercard、Apple Pay 感应付款**九巴（KMB）、龍運巴士（LWB）以及城巴均支持。
- 支付宝和微信巴士可用于香港九巴及城巴巴士。但并不是每条路线使用体验都一样：如果遇到微信无法付款，建议带现金备用。
- **巴士通常不找零钱**，使用现金时备好零钱。
- 儿童及长者优惠因路线与票种而异；12 岁以下儿童及长者的折扣，也提到成人陪同、不占座位的三岁以下幼儿优惠。

## 🎟️ 各类交通套票怎么选

| 票种／方式 | 适合情况 | 提示 |
| --- | --- | --- |
| 港铁游客全日通 | 一天多次乘港铁 | 按首次入闸计算 24 小时 |
| 八达通 | 港铁、巴士、日常小额消费 | 适合不同交通工具之间自由换乘 |
| 巴士单程付费 | 想省钱、以巴士为主 | 可用支持的感应银行卡／手机钱包或零钱 |

| 机场 E 线巴士 | 预算优先、可接受途经较多站点 | 按实际起点选择相应线路 |
| 港铁东涌线 + S1 | 想用较低费用抵达机场 | 东涌站转机场穿梭巴士 |
| 天星小轮 | 尖沙咀往返中环等跨海观景 | 兼顾交通与维港风景 |

# ✈️ 香港机场：省钱交通、行李与离境税

## 🚌 从市中心去机场：三种常见方案

### 💰 方案一：东涌线 → S1（省钱）

1. 从市区转乘港铁**东涌线**，到终点**东涌站**。
2. 出站后前往附近的 **S1 机场穿梭巴士**站。
3. 搭 S1 到香港国际机场航站楼。原攻略车费约 **HK$3.7**，东涌至机场约十多分钟。

**行李提示**：中环一带转东涌线可能要走较长距离，有大件行李时可比较下面的机场巴士方案。

### 🧳 方案二：A 线机场巴士（带行李省力）

- A 开头的机场巴士常从市区直接开往机场。例如从**金钟一带乘 A11**，参考车费 **HK$41.9**。
- 到机场的**离境／出发层**下车，附近有行李推车，带箱子比较省力。
- [A11 线路参考](https://hkbus.fandom.com/wiki/%E5%9F%8E%E5%B7%B4A11%E7%B7%9A)

### 🚌 方案三：E 线机场巴士

- E 开头的巴士也可联系机场与市区／东涌周边，适合预算优先的旅客。
- 相比直达型的机场交通，线路可能经过更多站点；可在香港机场公共巴士列表中选择从住宿区出发的 A／E 线。
- [香港国际机场：公共巴士](https://www.hongkongairport.com/tc/transport/to-from-airport/public-buses.page#content2)

**另一选择：机场快线。** 速度较快，适合需要快速直达的人，但车票较贵；从中环部分站点前往站台可能需要较长的站内步行。

## 🧳 机场提前办理登机与托运行李

- 香港机场可以在较早的时段办理登机手续；**国泰航空可提前约 24 小时办理登机及托运行李**。
- 可以早上到机场后，直接到国泰柜台完成值机和行李托运，再轻装乘 **S1** 到东涌游玩。
- **24 小时开放的机场不等于每家航空公司都全天办理托运**；可直接向所乘航空公司的值机柜台询问最早办理时间。
- [国泰航空自助值机／领取登机牌说明](https://www.cathaypacific.com/cx/zh_HK/faqs/check-in/check-in-kiosk/what-are-the-earliest-and-latest-times-that-I-can-check-in-and-collect-my-boarding-pass.html)

## 🧾 机场旅客离境税豁免与退款

- 香港飞机乘客离境税从原来的 **HK$120** 调整为 **HK$200**。豁免范围包括：**乘飞机抵港后于抵达当天或次日乘飞机离港**，以及**以飞机以外方式入境香港、于抵达当天或次日从香港机场乘飞机离境**的合资格旅客。
- **深圳陆路／海路到香港、随后从香港机场搭飞机离境**，是值得关注离境税豁免的情形。

### 📋 退款操作经验

1. 保存完整的**登机牌**，最好拍照备份。
2. 向航空公司索取列明税费的**电子客票收据或 invoice**，尤其是不同航司签发和承运的机票。
3. 使用 [APDT 离境税退款平台](https://www.apdtrefund.hk/) 申请适用的退款。
4. 办理离境手续后在手机填写申请，取得二维码，再到机场内指定货币兑换柜台领取港币现金。
5. 也有旅客选择支付宝、微信或银行卡收款；但是有手续费，因此**现场领取现金**是值得比较的选项。

**申请时间**：合格旅客（包括儿童及转机旅客）可在航班起飞后 **28 天内**申请。

### 🏨 东涌机场附近住宿

- **诺富特东荟城酒店（Novotel Citygate Hong Kong）**：笔记提到酒店机场接送服务，方便结合东涌购物和大屿山游览。
- **东荟城名店仓（Citygate Outlets）**：东涌站附近的奥特莱斯；原攻略还提到地下一层有超市。
- 行李寄存参考：[东荟城商场服务](https://www.citygateoutlets.com.hk/zh-hk/visit/mall-services/)、[昂坪 360 旅客服务](https://www.np360.com.hk/tc/visitor-information/tourist-guide#guest-services-section)。

# 🌃 尖沙咀、维多利亚港与天星小轮

## 🌊 星光大道与维港夜景

- **尖沙咀星光大道**：可以欣赏港岛的高楼天际线、海港与李小龙铜像，适合白天及夜间拍摄。
- **幻彩咏香江**：推荐晚上 **20:00** 在维港沿岸欣赏灯光秀。
- **香港艺术馆**：在尖沙咀海滨游览时非常适合穿插参观。馆内有**空调、休息座位**，从可看海的位置欣赏维多利亚港及港岛天际线，夏季可边休息边观景。
- 其他海港角度：**红磡、观塘海滨步道、鲤鱼门**，适合欣赏不同角度的城市和夕阳。

## ⛴️ 天星小轮：尖沙咀 → 中环

1. 在尖沙咀海滨游览星光大道后，步行前往**尖沙咀天星码头**。
2. 按码头指示选择前往**中环**的航线，候船、上船后横渡维多利亚港。
3. 船上可从海面欣赏尖沙咀与港岛两侧的高楼。
4. 在**中环天星码头**下船，顺路参观**香港摩天轮**、**香港海事博物馆**，也可继续乘巴士前往太平山顶。

- **普通渡轮**与**维港海港游**是不同服务；海港游柜台购票可使用现金、信用卡或支付宝／微信等支付方式。
- [天星小轮航线及服务](https://www.starferry.com.hk/tc/service)

## 🖼️ 尖沙咀其他博物馆

- **香港太空馆**：在尖沙咀文化区，可以与海滨步行结合。
- **香港科学馆**：适合亲子参观。原攻略提到从尖沙咀站地下通道往 **P2** 方向走，有直梯可用。
- **免费参观时间**：**科学馆及太空馆星期三免费**，可以按这个时间安排文化场馆。

# ⛰️ 太平山顶：巴士与步行上山

## 🚌 城巴 15／X15：中环出发

**推荐连游**：尖沙咀 → 天星小轮 → 中环码头 → 太平山顶。

1. 从**中环天星码头**下船，前往**中环 5 号码头／附近巴士站**；也可以从**中环交易广场**或**金钟 C1 出口**附近的站点搭车。
2. 乘坐 **城巴 15／X15** 往**山顶**方向。
3. 到站后步行往**山顶狮子亭**，欣赏维多利亚港、港岛高楼与九龙天际线。
4. 傍晚至夜间适合看山顶夜景。

## 🚶 从中环步行登山

- 另一种玩法是从中环搭乘**中环至半山自动扶梯**向上，走到扶梯系统较高处后，再按步行导航上山；步行约 **40 分钟**。
- 如希望减少爬坡，可优先选 15／X15 巴士。

# 🪷 大屿山：东涌、昂坪、天坛大佛与大澳

## 🚌 东涌坐 23 路巴士去天坛大佛

1. 先到港铁**东涌站**；从机场出发也可坐 **S1**，约十多分钟到东涌一带。
2. 出站后沿**昂坪／大屿山巴士**指示过马路，找到**新大屿山巴士 23 路**上车点。
3. 搭 **23 路**前往昂坪，参观**天坛大佛、宝莲禅寺**。
4. 从昂坪可继续走到**心经简林**，根据体力选择短程步道或山路。

- **23 路曾遇到微信付款不成功**，搭车可准备零钱或其他支付方式。
- **昂坪市集附近不方便找 ATM**，去之前可在东涌准备港币现金。

## 🚠 昂坪 360 缆车

- 从东涌也可以乘**昂坪 360 缆车**上山。对于希望少换乘、欣赏大屿山山海风景的游客，是另一种选择。
- 搭缆车到昂坪后，游览路线同样可以接上**天坛大佛 → 宝莲禅寺 → 心经简林**。

## 🛕 推荐昂坪步行顺序

**天坛大佛 → 宝莲禅寺（可吃午饭）→ 心经简林 → 昂坪市集 → 返回东涌／继续前往大澳**。

- **宝莲禅寺**：既可参观寺院，也适合安排素食午餐。
- **天坛大佛**：适合不同年龄层；如果喜欢徒步，周边还有山路选择。
- **大屿山凤凰山**：是具有挑战性的登山目的地，适合有经验、体力较好的人。

## 🛶 从昂坪去大澳与乘船

- 游完昂坪后，可乘**巴士前往大澳**，体验渔村、水边街道和大屿山另一面。
- 大澳可以水路离开可结合目的地选择轮渡，不必原路全部乘巴士返回。
- [大澳渡轮资料](https://www.fortuneferry.com.hk/zh/news/sailing-news-tuen-mun-to-tai-o-route/36)

# 🏙️ 其他香港景点与街区

## 🎢 海洋公园与迪士尼

- **香港海洋公园**：可以单独玩一整天，适合喜欢动物、海洋主题和游乐设施的游客。
- **香港迪士尼乐园**：适合亲子及主题乐园爱好者；门票参考：[Klook](https://www.klook.com/zh-TW/activity/39-hong-kong-disneyland-resort-hong-kong/)、[KKday](https://www.kkday.com/zh-my/product/2301-hong-kong-disneyland-ticket)。

## 🌿 港岛与文化景点

- **浅水湾、赤柱**：海湾、海滨步行和港岛南区风景。
- **黄大仙祠**：宗教文化景点。
- **香港摩天轮**：中环码头旁，适合搭完天星小轮后顺道体验。
- **香港海事博物馆**：中环海滨附近，介绍香港从渔港到国际海港的发展；有空调，可以结合炎热天气安排。
- **香港故宫文化博物馆**：适合对艺术文物感兴趣的游客，也可与西九文化区和海景散步相结合。

## 🛍️ 商圈、街市和买东西

- **旺角、油麻地**：更接近当地日常消费的街区，可逛传统街市、小店与大排档，适合寻找价格亲民的餐饮和生活用品。
- **油麻地大排档**：比较推荐的平价吃饭方式；想吃得更本地化，可以选择居民常去的食肆而不只是景点餐厅。
- **铜锣湾**：热闹的购物餐饮区，有 **时代广场、SOGO 崇光百货** 等。
- **中环置地广场（Landmark）**：高端品牌商场。
- **金钟太古广场（Pacific Place）**：高端购物中心，可与港岛交通和太平山顶游览搭配。
- **东涌东荟城名店仓**：适合去机场或大屿山途中购物，地下有超市。

# 🍜 香港美食与用餐习惯

## 🥢 推荐尝试

- **港式早茶**：点心、茶饮；建议 **09:00 之后**再去，比较符合当地用餐节奏。
- **粤菜和煲汤**：港式靓汤、传统粤菜和各种点心。
- **海鲜**：尤其是生蚝、鱼虾等，适合多人共享。
- **甜品**：双皮奶、芒果椰汁类甜品；比如**许留山**的芒果甜品。
- **本地大排档**：油麻地一带更适合寻找平价街坊餐馆。
- **知名餐厅备选**：比如**镛记、利苑**等粤菜餐厅；可按预算选择名店或普通街坊食肆。

## 🕰️ 用餐时间

- 早茶可安排在 **09:00–11:00** 左右。
- 当地午餐有时延后至 **14:00** 左右，晚饭也常在 **19:00–20:00**。
- 希望避开排队时，可以错开最热门的吃饭时间。

# 🧭 实用交通与省钱 Tips

- **尖沙咀到中环**：推荐搭天星小轮；兼顾跨海交通与欣赏维港。
- **中环到太平山顶**：乘 **15／X15 巴士**，再步行到狮子亭。
- **机场到东涌**：乘 **S1 巴士**；东涌也可换 **23 路**去昂坪大佛。
- **深圳到九龙**：陆路过境后在**上水**换九巴往九龙，是便宜走法。
- **香港机场离境**：可比较**东涌线 + S1、A／E 巴士、机场快线**，按价格及带行李的便利性决定。
- **付款**：准备**八达通、支持感应的银行卡／Apple Pay，以及适量港币零钱**；支付宝、微信可作为额外方式。
- **出租车**：备现金；**Uber** 在香港很方便。
- **炎热天气**：逛维港时穿插**香港艺术馆、海事博物馆、科学馆／太空馆**，可吹空调并休息。
- **免费时段**：**香港科学馆、太空馆星期三免费**，适合搭配尖沙咀一带游览。
